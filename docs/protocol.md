# Протокол обмена, версия 1

MCP-сервер и обработка `MCPLocalBridge` обмениваются файлами JSON в UTF-8 (обработка пишет с BOM, MCP - без
него; читать нужно с допуском BOM). Время везде - UTC в формате `ГГГГ-ММ-ДДTчч:мм:сс`.

## Каталоги

Корень - `%TEMP%\mcp-1c-local-bridge\` пользователя Windows (обработка берёт `КаталогВременныхФайлов()`).
Каждая открытая форма обработки заводит свой каталог сеанса с новым идентификатором из 8 шестнадцатеричных
символов и удаляет его при закрытии формы.

```
<корень>\
  .clock                  проба часов: MCP пишет файл и берёт его время изменения как текущее время Windows
  <сеанс>\
    session.json          сведения о сеансе и сердцебиение (пишет обработка)
    in\<команда>.json     входящие команды (пишет MCP)
    work\<команда>.json   команда, взятая в работу (обработка переносит её из in)
    out\<команда>.json    ответ (пишет обработка)
```

Запись без промежуточных состояний: MCP пишет `in\<команда>.tmp` и переименовывает в `.json`, обработка так же
пишет ответ через `out\<команда>.tmp`. Обработка ищет только `*.json`.

## session.json

Обработка переписывает файл при открытии формы, раз в 2 секунды, перед командой и после неё.

| Поле | Значение |
| --- | --- |
| `protocol` | версия протокола, 1 |
| `bridgeVersion` | версия обработки |
| `session` | идентификатор сеанса моста (имя каталога) |
| `path` | каталог сеанса в Windows |
| `infobase` | `СтрокаСоединенияИнформационнойБазы()` |
| `user`, `userFullName` | имя и полное имя пользователя 1С |
| `sessionNumber` | номер сеанса информационной базы |
| `configuration`, `configurationSynonym`, `configurationVersion`, `compatibilityMode` | конфигурация |
| `platform`, `serverPlatform` | версия клиента и сервера 1С |
| `started`, `heartbeat` | открытие формы и последнее сердцебиение |
| `state` | `ready`, `busy` (выполняет команду), `awaiting` (результат ждёт решения пользователя), `paused` (приостановлен на форме) |
| `busyCommand` | идентификатор выполняемой команды или команды, чей результат ждёт решения; иначе пустая строка |
| `mode` | `auto` - ответы уходят сразу, `manual` - после решения пользователя |
| `allowWrite`, `allowClientCode` | разрешения «Запись в базу» и «Код на клиенте» |
| `commandsDone` | сколько команд выполнено |

Возраст сердцебиения MCP считает по времени изменения `session.json` и пробы `.clock` - оба ставит Windows,
поэтому расхождение часов WSL и Windows (бывает после сна) не мешает. Сеанс молчит дольше 10 секунд и не
занят командой - он не отвечает (форма закрыта без уборки, клиент упал или открыто модальное окно). Каталоги
сеансов, молчащих больше суток, MCP удаляет.

## Команда

```json
{"protocol": 1, "id": "20261021T101500123-a1b2", "type": "query", "ttlSec": 60, "text": "ВЫБРАТЬ 1", "rowLimit": 1000}
```

| Поле | Для каких команд | Значение |
| --- | --- | --- |
| `id` | все | идентификатор: момент создания UTC и случайный суффикс, поэтому порядок имён - порядок поступления |
| `type` | все | `ping`, `query`, `eval`, `execute`, `metadata` |
| `ttlSec` | все | срок, за который обработка должна начать команду, считая от времени изменения файла |
| `text`, `params`, `rowLimit` | `query` | текст запроса, параметры, предел строк каждого результата |
| `expression` | `eval` | выражение для `Вычислить()` |
| `code` | `execute` | код для `Выполнить()`; результат - переменная `Результат` |
| `side` | `eval`, `execute` | `server` или `client` |
| `allowWrite` | `eval`, `execute` | `true` - выполнить без отката транзакции; без разрешения «Запись в базу» на форме код выполняется с откатом и предупреждением |
| `path`, `filter` | `metadata` | полное имя объекта; отбор состава конфигурации |

Обработка выполняет команды по одной в порядке имён. Перед выполнением она переносит файл в `work`; если
перенос не удался, команду уже снял MCP. Просроченную по `ttlSec` команду обработка не выполняет и отвечает
`expired`.

В режиме `manual` выполненная команда остаётся в `work`, а ответ - в памяти формы, пока пользователь не решит:
«Отдать агенту» пишет ответ как есть, «Не отдавать» - ответ `denied` без результата. До решения `state` -
`awaiting`, и следующие команды не начинаются.

MCP снимает команду сам, если она не начата за время ожидания вызова: удаляет её из `in`. Удалось - команда не
выполнится; файла уже нет - обработка её взяла, и вызов возвращает идентификатор для инструмента `result`.

## Ответ

```json
{"protocol": 1, "id": "20261021T101500123-a1b2", "status": "ok", "durationMs": 35, "result": {}, "messages": []}
```

| Поле | Значение |
| --- | --- |
| `status` | `ok`, `error` (исключение 1С), `rejected` (код на клиенте не разрешён на форме или неизвестная команда), `expired`, `denied` (пользователь не отдал результат) |
| `result` | результат для `ok` |
| `error`, `errorDetails` | описание ошибки и `ПодробноеПредставлениеОшибки()` |
| `messages` | сообщения пользователю, выданные на сервере во время команды |
| `rolledBack` | `true` - серверный `eval`/`execute` выполнялся в транзакции с откатом |
| `warnings` | предупреждения: запись запрошена, но выполнена с откатом; код оставил незавершённую транзакцию |
| `durationMs` | время выполнения на стороне обработки |

## Значения 1С в JSON

| Значение 1С | JSON |
| --- | --- |
| Строка, Число, Булево | как есть |
| Дата | строка `ГГГГ-ММ-ДДTчч:мм:сс` |
| Неопределено, NULL | `null` |
| УникальныйИдентификатор | строка |
| Ссылка | `{"_type": "<полное имя>", "_uuid": "...", "_presentation": "..."}` |
| Значение перечисления | `{"_type": "Перечисление.<Имя>", "_name": "<имя значения>", "_presentation": "..."}` |
| Массив, Структура, Соответствие со строковыми ключами | массив или объект |
| Соответствие с другими ключами | `{"_type": "Соответствие", "pairs": [{"key": ..., "value": ...}]}` |
| ТаблицаЗначений, результат запроса, набор записей регистра | `{"columns": [{"name", "types"}], "rows": [[...]], "total": N, "truncated": bool}` |
| ДеревоЗначений | то же, строки - `{"values": [...], "rows": [...]}` |
| СписокЗначений | `{"_type": "СписокЗначений", "items": [{"value", "presentation", "check"}]}` |
| Объект справочника, документа и т. п. | `{"_type": "<полное имя>.Объект", "isNew": bool, "fields": {...}}` с табличными частями |
| ОписаниеТипов | `{"_type": "ОписаниеТипов", "types": ["Строка(100)", "Справочник.Контрагенты"]}` |
| Тип, ОбъектМетаданных | строка: имя типа, полное имя объекта |
| ДвоичныеДанные | `{"_type": "ДвоичныеДанные", "size": N}` |
| прочее | `{"_type": "<тип>", "_presentation": "..."}` |

Вложенность ограничена 12 уровнями, строки таблиц и выборок - `rowLimit` (для `eval` и `execute` - 1000).
Ответ `query` - `{"results": [...]}` с результатом каждого запроса пакета; на месте `УНИЧТОЖИТЬ` - `null`.
