# Заметки для агента

- Две части: MCP-сервер `src/mcp_1c_local_bridge/` (Python, FastMCP из пакета `mcp` 1.x - 2.x переименовал
  FastMCP, поэтому `mcp<2`) и обработка `epf/` (XML-выгрузка; собранный файл - `dist/MCPLocalBridge.epf`).
  Протокол между ними - `docs/protocol.md`: меняешь поля команды или ответа - меняй обе стороны и документ.
- Проверка MCP-стороны: `uv run pytest` (имитация обработки в потоке, `tests/test_bridge.py`).
- Сборка обработки: `scripts/build-epf.ps1 -Server <сервер> -Ref <база>` в Windows PowerShell; исходники скрипт
  сам копирует на локальный диск. Сборка не проверяет синтаксис модулей - он виден только при открытии
  обработки в 1С. Доступность методов в контексте (тонкий клиент, сервер) сверять со справкой платформы:
  `ТекущаяУниверсальнаяДата()` и `ПолучитьСообщенияПользователю()` на клиенте недоступны.
- Обработка должна работать в режиме совместимости 8.3.14: без `Асинх`/`Ждать`, WebSocket и методов новее.
  Обработчик ожидания с интервалом меньше секунды - только однократный, его переподключают после опроса.
- Модули `.bsl` - UTF-8 с BOM и CRLF, пустые строки внутри блоков - с табами отступа блока. Инструменты правки
  нередко срезают эти табы и меняют переводы строк: после правки проверить и вернуть.
- Каталог обмена по умолчанию - `%TEMP%\mcp-1c-local-bridge` у обеих сторон. Свой задаётся на форме обработки
  (`ХранилищеОбщихНастроек`, `MCPLocalBridge`/`КаталогОбмена`) и в `MCP_1C_BRIDGE_DIR` у MCP: автоматически
  стороны его не согласуют. В корне MCP трогает только папки с именем сеанса (8 hex): корень может быть общим.
- Версия - в трёх местах: `pyproject.toml`, `src/mcp_1c_local_bridge/__init__.py` и `bridgeVersion` в
  `СведенияСеанса()` модуля формы.
- Форма - одно поле HTML на встроенном WebKit 1С (`V8WebKit`, проверено на 8.3.27): страницу целиком строит
  `ТекстСтраницы()` только при открытии, дальше блоки и строки журнала меняют её функции JavaScript (`setBlock`,
  `addEntry`, `updateEntry`), вызываемые через `Элементы.ПанельHTML.Документ.defaultView`; если вызов не удался -
  страница перерисовывается целиком. Действия - ссылки `#act:<действие>`, их разбирает `ПанельHTMLПриНажатии`.
- Представления ссылок обработка получает пакетно (`ЗагрузитьПредставления`): `Строка(Ссылка)` без кэша - запрос
  к базе на каждую ссылку, 3000 ссылок - около 10 с.
- Живой сеанс 1С через мост - это подключение к рабочей базе: команды шлются только с согласия пользователя.
